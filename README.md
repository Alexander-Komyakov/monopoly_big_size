# Банк монополии большего размера


Создан для упрощения игры. Вместо подсчета, размена и передачи бумажных купюр используются карточки. Их можно прикладывать для проверки баланса. Добавлять на них деньги, уменьшать или перводить. Для вывода информации используется экран `2,8` дюйма `240x320`. Для чтения карточек `RFID-RC522` и для ввода матричная клавиатура 4x4.

## Детали

- RFID-модуль Arduino RC522 с картой и брелоком 
- Матричная клавиатура 4x4
- Дисплей 2.8" 240x320, SPI
- Контроллер RP2040 TYPE-C 16MB
- Аккумулятор 3.3V 1000mAh
- TP4056 для безопасной зарядки/разрядки
- Переключатель трехконтактный

## Сборка

Зажимаем клавишу boot на rp2040 и подключаем usb. В ОС появится блочное устройство. Копируем на него firmware.uf2

Для сборки проекта устанавливаем python и зависимости из requirements.txt с помощью pip; `pip install -r requirements.txt`. Подключаем по microusb к компьютеру rp2040, при запуске зажимаем клавишу usr на 3 секунды. В системе появится девай `/dev/ttyACM0`
Далее с помощью mpremote копируем файлы на rp2040:
```
mpremote cp keypad.py :keypad.py
mpremote cp mfrc522.py :mfrc522.py
mpremote cp main.py :main.py
```

## Пайка

### Матричная панель

Слева направо напрямую подключаем пины к `rp2040` в `gp0,4,5,6,7,13,14,15`


### Дисплей

- VCC - 3.3V

- GND - GND

- LED = GP21

- RESET = GP20

- DC = GP12

- CS = GP1

- SCK = GP2

- MOSI = GP3


### RFID-RC522

- 3.3V - 3.3V

- GND - GND

- RST - GP22

- SDA - GP9

- SCK - GP10

- MOSI - GP11

- MISO - GP8

## Логика банка монополии:

Возможны три действия:
  1. Получение денег от банка
  2. Передача денег банку
  3. Передача денег между игроками
  4. Сброс до 1500 всем игрокам
  4. Запись новых карточек или запись карточек после сброса

### Получение денег от банка:
  Нажимаем плюс, пишем сумму, нажимаем апрув, прикладываем RFID метку, происходит запись


### Передача денег банку:
  Нажимаем минус, пишем сумму, нажимаем апрув, прикладываем RFID метку, происходит запись

  Если не хватает денег, то сообщает об этом и не происходит запись
  Баланс не может быть отрицательным

### Передача денег между игроками:
  Нажимаем на кнопку передачи денег, пишем передаваемую сумму, нажимаем апрув, прикладываем от кого, прикладываем кому, нажимаем апрув

  Если деньги у игрока закончились, то отмена операции и вывести сколько не хватает

### Запись новых карточек или запись карточек после сброса:
  Прикладываем карту, вводим от 1 до 8 число, нажимаем A. Теперь введеное число это номер игрока




### Кнопки:
'0-9' для написания числа

'D' - Стереть символ

'A' - Принять операцию - апрув - подтверждение

'#' - Минус

'*' - Плюс

'B' - Передача денег - действие

'C' - Отмена

Для сброса всех игроков на 1500 введите B99123A
Для сброса всех игроков на 1500 и сброса карточек игроков введите B99124A


### Печать

Для печати используем два файла в models. main и up stl
Включаем поддержки, 15% заполнение и печатаем
